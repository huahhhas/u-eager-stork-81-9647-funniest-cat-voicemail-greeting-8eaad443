# Funniest Cat Voicemail Greeting

One line, at most 120 characters: the funniest voicemail greeting a cat would record.

> Hi, it's Miso. I'm napping in the box you bought me. Leave a message after the beep — or slide tuna under the door.

## Entry

`main.py` prints the greeting; `entry.txt` holds exactly that line (115 characters).

## Run

```sh
python3 main.py
```
